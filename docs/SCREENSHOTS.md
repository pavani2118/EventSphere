# Final Report Screenshot Checklist

Capture screenshots from a configured test environment only. Do not use
fabricated data, production secrets, or another user's private information.

## Public and attendee views

- [ ] Login page
- [ ] Registration page
- [ ] Homepage
- [ ] Event listing with search and category filter
- [ ] Event details and ticket booking form
- [ ] Booking confirmation
- [ ] My Bookings with payment and cancellation state
- [ ] My Tickets with QR code and ticket status
- [ ] Notifications page
- [ ] My Waitlist with status and event details
- [ ] Private venue-hire availability and price result
- [ ] Venue-hire request history

## Administration

- [ ] Admin dashboard statistics
- [ ] Recent bookings table
- [ ] Agent message log
- [ ] Venue management
- [ ] Event management
- [ ] Ticket-category management

## Gate operations

- [ ] Gate scanner access screen
- [ ] Successful valid-ticket check-in
- [ ] Duplicate check-in rejection
- [ ] Cancelled or invalid-ticket rejection

## Capture requirements

Each screenshot should show the page title or relevant navigation context,
avoid credentials and private tokens, and be labelled with the test account
role and date in the report notes. Capture both a desktop workflow and at
least one mobile-responsive page.
